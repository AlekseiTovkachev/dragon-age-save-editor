# Manual Testing

Use copied saves only.

## DAO Vanilla

- [ ] Open a vanilla DAO save.
- [ ] Confirm the starting tab is `Characters`.
- [ ] Confirm `Plot Flags` is hidden.
- [ ] Confirm Awakening-only material tiers 8 and 9 are not shown.
- [ ] Confirm Awakening-only abilities with IDs `>= 400000` are not shown.
- [ ] Edit level, experience, approval, attributes, and point pools.
- [ ] Edit abilities from unlocked trees.
- [ ] Edit a stackable backpack item stack size.
- [ ] Clone a non-stackable backpack item.
- [ ] Edit known crafting recipes.
- [ ] Save As, reload, and confirm changes persist.

## Awakening, Witch Hunt, And Golems

- [ ] Open one Awakening-style save from each available campaign.
- [ ] Confirm the app identifies the save as DAO Awakening.
- [ ] Confirm Awakening material tiers are available where relevant.
- [ ] Confirm Awakening abilities are available.
- [ ] Confirm `Plot Flags` is hidden.
- [ ] Save As, reload, and confirm changes persist.

## DA2

- [ ] Open a DA2 save.
- [ ] Confirm `Plot Flags` is visible.
- [ ] Confirm the skills column is hidden.
- [ ] Confirm DA2 abilities show useful Add/Remove tree rows.
- [ ] Confirm item property powers display as floats.
- [ ] Edit a stackable backpack item stack size.
- [ ] Clone a non-stackable backpack item.
- [ ] Edit recipes.
- [ ] Edit DA2 plot flags.
- [ ] Save As, reload, and confirm changes persist.
